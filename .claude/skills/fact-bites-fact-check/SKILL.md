# Fact Bites Fact-Check

- Break narration into atomic, checkable claims.
- Prefer primary sources: peer-reviewed papers, government science agencies, universities, museums, official datasets, and original research releases.
- For scientific claims, locate the original paper and verify wording, sample size, method, uncertainty, and publication date.
- Distinguish measured results from estimates, hypotheses, and popular summaries.
- Check statistic denominator, units, timeframe, and currentness.
- Never invent a citation, quote, source title, URL, or researcher.
- If web access is unavailable, mark the claim UNVERIFIED.
- Flag sensational hooks that overstate the evidence.
- Return claim-by-claim status (SUPPORTED / QUALIFIED / UNVERIFIED / CONTRADICTED), evidence, source URL, safer replacement, and overall PASS / PASS WITH CHANGES / HOLD.
- Model agreement is not evidence; independently verify primary sources.
