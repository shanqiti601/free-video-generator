# Fact Bites YouTube Publishing

Prepare metadata only after the script and video pass fact-check and QA.

- Write one accurate, curiosity-led title that does not mislead.
- Provide a concise description with central fact and source/footage credits.
- Include relevant search phrases and a small set of non-spammy hashtags.
- Suggest a meaningful pinned-comment question.
- Suggest a 2–5 word mobile-readable thumbnail phrase.
- Never promise a result the video does not deliver or use unrelated trending keywords.
- Preserve required source credits and licensing.
- Never publish automatically without explicit user authorization.
